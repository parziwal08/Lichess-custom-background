This is a lichess userscript to customize background on pages containing a board.

It adds the option to upload a background image from pc or url.

Install tampermonkey browser extension.
Go to dashboard and click on the + icon to create a new script.
Paste the contents of the .json file in the editor and hit ctrl + s, and you're good to go.

This was created using an online-go.com userscript created by my friend, Soumya (soumyak4.in). I prompted Gemini to port the background functionality of his script to lichess, and tweaked some things, made the move section transparent and added a slider to adjust its opacity.
