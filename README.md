This is a lichess userscript to customize background on lichess webpages containing a board.

**Features:**
1. "Set background" button at the bottom-left of the page, which lets you upload a background image from pc or url.
2. Adjust the opacity of the movelist section with a slider at the bottom left.
3. Press T to toggle chatbox on/off on analysis page. It is off by default to have more of the background.

**How to install:**
1. Install tampermonkey browser extension.
2. Go to dashboard and click on the "+" icon to create a new script.
3. Paste the contents of the .json file in the editor (or drag and drop the file in the editor), hit ctrl + s, and you're good to go.

This was made using an [online-go.com userscript](https://github.com/SoumyaK4/OGS-Tampermonkey) created by my friend, Soumya (https://soumyak4.in/). I prompted Gemini to port the background functionality of his script to lichess, and tweaked some things, made the movelist section transparent and added a slider to adjust its opacity.
