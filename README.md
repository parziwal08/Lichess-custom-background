This is a lichess userscript to customize background on lichess webpages containing a board.

User can upload a background image from pc or url.

How to install:

1. Install tampermonkey browser extension.
2. Go to dashboard and click on the "+" icon to create a new script.
3. Paste the contents of the .json file in the editor (or just drag and drop the file in the editor) and hit ctrl + s, and you're good to go.

This was created using an [online-go.com userscript] (https://github.com/SoumyaK4/OGS-Tampermonkey) created by my friend, Soumya (https://soumyak4.in/). I prompted Gemini to port the background functionality of his script to lichess, and tweaked some things, made the move section transparent and added a slider to adjust its opacity.
